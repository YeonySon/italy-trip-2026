# 이탈리아 여행 2026

2026년 12월 21–30일 로마·베네치아·피렌체·피사 일정, 예약 체크리스트, 장소 정리 웹앱입니다.

- **설치:** 아이폰은 Safari 공유 버튼에서 "홈 화면에 추가", 안드로이드는 Chrome 메뉴에서 "앱 설치"를 누릅니다. 설치하면 인터넷 없이도 열립니다.
- **편집:** 오른쪽 위 "편집"을 누른 뒤 고칠 항목을 누릅니다. 바꾼 내용은 바로 저장됩니다.
- **저장 위치:** 고친 내용과 체크 표시는 각 기기 브라우저 안에만 저장되고 이 저장소에는 올라오지 않습니다.
- **기기 간 옮기기:** 정보 탭의 "백업 내보내기"로 파일을 만들고, 다른 기기에서 "백업 불러오기"로 엽니다.

파일 구성: `index.html`(앱 틀), `app.js`(화면과 편집), `data.js`(기본 일정 데이터), `styles.css`, `sw.js`(오프라인), `manifest.webmanifest`.
