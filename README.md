# 이탈리아 여행 2026

2026년 12월 21–30일 로마·피렌체·피사·베네치아 일정, 예약 체크리스트, 장소 정리 웹앱입니다.

- **설치:** 아이폰은 Safari 공유 버튼에서 "홈 화면에 추가", 안드로이드는 Chrome 메뉴에서 "앱 설치"를 누릅니다. 설치하면 인터넷 없이도 열립니다.
- **보기:** 누구나 볼 수 있고, 일정은 앱을 열 때마다 최신 내용으로 바뀝니다.
- **편집:** 저장소 주인과 협업자만 할 수 있습니다. 앱의 정보 탭 → "편집 권한 연결"에 GitHub 토큰을 넣으면 편집 버튼이 생기고, 고친 내용은 몇 초 뒤 `plan.json`에 저장되어 모든 사람에게 반영됩니다.
  - 주인: Fine-grained 토큰, 이 저장소만, Contents 읽기/쓰기
  - 협업자: 초대를 수락한 뒤 classic 토큰, `public_repo` 권한
- **되돌리기:** `plan.json`의 커밋 기록에서 이전 버전을 볼 수 있습니다.

파일 구성: `index.html`(앱 틀), `app.js`(화면, 편집, GitHub 저장), `plan.json`(공유 일정), `data.js`(처음 열 때 쓰는 기본 일정), `styles.css`, `sw.js`(오프라인), `manifest.webmanifest`.
