# 이탈리아 여행 2026

2026년 12월 21–30일 로마·피렌체·피사·베네치아 일정 웹앱입니다. https://yeonyson.github.io/italy-trip-2026/

- **설치:** 아이폰은 Safari 공유 버튼에서 "홈 화면에 추가", 안드로이드는 Chrome 메뉴에서 "앱 설치". 설치하면 인터넷 없이도 열립니다.
- **보기:** 누구나 볼 수 있습니다. 일정은 앱을 열 때마다 최신 내용으로 바뀝니다.
- **편집:** 일정 데이터는 따로 둔 저장소 [italy-trip-2026-data](https://github.com/YeonySon/italy-trip-2026-data)의 `plan.json`에 있습니다. 앱의 정보 탭에서 "편집 권한 연결"을 누르고 그 저장소에 쓸 수 있는 GitHub 토큰을 넣으면 편집 버튼이 생깁니다. 고친 내용은 몇 초 뒤 모든 사람에게 반영됩니다.
  - 주인: Fine-grained 토큰. Repository access는 `italy-trip-2026-data` 하나, 권한은 Contents 읽기/쓰기만.
  - 협업자: `italy-trip-2026-data`에만 초대합니다. 수락한 뒤 classic 토큰(`public_repo`)을 만들어 넣습니다. 이 앱 저장소에는 초대하지 마세요.
- **기능:** 일정·예약 체크리스트·장소(구글 평점 4.6 이상), 지도·길찾기·블로그 후기, 교통·예약 바로가기, 날씨 예보(여행 약 2주 전부터), 환율 계산기, 여행 경비와 정산, 끌어서 순서 바꾸기.
- **공개 주의:** 두 저장소 모두 공개입니다. 예약번호, 여권번호, 연락처 같은 개인정보는 적지 마세요.

파일 구성: `index.html`(앱 틀과 보안 정책), `app.js`(화면·편집·GitHub 저장·날씨·환율·경비), `data.js`(처음 열 때나 오프라인일 때 쓰는 기본 일정), `styles.css`, `sw.js`(오프라인), `manifest.webmanifest`.
